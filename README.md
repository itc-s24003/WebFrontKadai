# ゲーム紹介サイト

## **機能**
好きなゲームの紹介サイト
ゲーム詳細ページ（タイトル・画像・紹介文・プレイ人数を表示）

## **ページ構成**
トップページ
ゲーム別詳細（タイトル・画像・紹介・プレイ人数・戻るリンク）

## **ディレクトリ構成（ゲーム紹介サイト）**
トップページ  
/app/layout.tsx => レイアウト  
/app/page.tsx => ページ定義   
  
詳細ページ  
/app/games/[id]/page.tsx => ゲーム詳細  

## **microcMS**  
/lib/microcms => microCMSからゲーム詳細データを取得
